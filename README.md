# Mobs

Addon para Minecraft Bedrock que transforma o Vanilla em um jogo de monster-taming.

## Estrutura

- BP/ — Behavior Pack (lógica, itens, entidades, scripts)
- RP/ — Resource Pack (texturas, textos, UI)

## Build

Junte BP/ + RP/ num .mcaddon (ZIP renomeado) para testar no MCPE.
